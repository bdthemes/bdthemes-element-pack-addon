Companion plugin for Element Pack Pro that carries the legacy widgets removed from the main plugin.

== Description ==

Element Pack Pro no longer bundles its deprecated widgets. This plugin brings them back, unchanged, for sites that still use them:

* Post widgets (Post Grid, Post List, Post Slider, Timeline, ...)
* Crypto Currency widgets
* bbPress, BuddyPress, Charitable, Give and Easy Digital Downloads integrations
* Age Gate, Air Pollution, Call Out, Dark Mode, Dropbar, Fancy Card, Honeycombs, Image Accordion, Member, Slinky Vertical Menu, Download Monitor, Everest Forms, Layer Slider

Requirements: Elementor and Element Pack Pro 9.9.3 or newer. The widgets appear in the Element Pack dashboard exactly where they used to, with the same on/off state.
